12306 车票候补模块（基础版）

这是一个使用 C 语言实现的 12306 车票候补排队系统模拟程序。系统基于链式队列数据结构，实现了“先候补先出票”的业务逻辑。

功能说明
1. 新增候补订单：输入订单号、姓名、身份证号，将订单加入队列尾部。
2. 余票发放：输入本次释放的余票数量，系统从队头开始依次处理候补订单，出票成功则打印订单信息。
3. 查看候补队列：查看当前排队等待的订单详情。
4. 退出程序：输入 0 退出系统。

技术实现
1. 数据结构：采用链式队列（Linked Queue），使用 front 和 rear 双指针管理，支持动态扩容。
2. 内存管理：出队时使用 free 释放节点内存，防止内存泄漏。
3. 边界处理：出队后若队头为空，同步将队尾置空，避免悬空指针。
4. 异常处理：使用 while(getchar() != '\n') 清空输入缓冲区，防止用户输入非法字符导致死循环。

编译与运行
确保已安装 C 语言编译器（如 GCC）。
编译命令：
gcc main.c -o waitlist
运行程序：
Windows 系统直接运行 waitlist.exe
Linux 或 macOS 系统运行 ./waitlist
